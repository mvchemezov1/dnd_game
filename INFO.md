## 📖 Руководства пользователей DnD Game (обновлённое)

Ниже — три инструкции для разных ролей. Они помогут вам быстро освоиться в системе и использовать её возможности, включая новые функции: крафт, торговля, диалоги и путешествия.

---

## 👾 Для игроков

*Добро пожаловать в мир приключений! Здесь вы управляете своим персонажем, участвуете в боях, находите сокровища, создаёте предметы, торгуете с другими игроками, общаетесь с NPC и путешествуете по миру.*

### 🔐 Вход и регистрация
1. Откройте страницу **«Вход»** (`/login.html`) или **«Регистрация»** (`/register.html`).
2. При регистрации придумайте сложный пароль (минимум 8 символов, заглавная, строчная, цифра и спецсимвол, например `Test123!`).
3. После входа вы получите **токен** — он сохранится в браузере автоматически и будет использоваться для всех запросов.

### 🧙 Управление персонажами
- Перейдите в **«Персонажи»** (`/characters.html`), чтобы увидеть список ваших героев.
- Нажмите **«Создать нового персонажа»** – укажите имя и начальные хиты (максимум 20–30).
- Кликните по имени персонажа, чтобы открыть его карточку (`/character.html?id=...`). Там вы увидите:
  - Характеристики (сила, ловкость, телосложение, интеллект, мудрость, харизма).
  - Навыки и спасброски.
  - Инвентарь и экипировку.
  - Текущие HP, временные HP, класс брони, скорость.

### ⚔️ Бой
- Перейдите в **«Бой»** (`/combat.html` или `/player/combat.html`).
- Введите ID боя (если вы участник) и нажмите **«Загрузить статус»**.
- Когда наступит ваш ход, вы сможете:
  - **Бросить инициативу** (если ещё не бросили).
  - **Совершить движение** (введите дистанцию в футах и нажмите «Двигаться»).
  - **Совершить стандартное действие** (атака, заклинание, рывок, уклонение, помощь, скрытие, подготовка и т.д.).
  - **Совершить бонусное действие** (если оно доступно).
- Все изменения отображаются в реальном времени (через WebSocket).

### 🎲 Крафт (создание предметов)
- Перейдите в **«Крафт»** (`/crafting.html`).
- Введите ID своего персонажа и нажмите **«Загрузить рецепты»**.
- Вы увидите список доступных рецептов (зависят от уровня, навыков и наличия инструментов).
- Выберите рецепт (нажмите «Выбрать»), затем нажмите **«Начать»**.
- Процесс крафта займёт определённое время (в игровых часах). Вы можете отслеживать прогресс в разделе **«Активные процессы»**.
- По окончании крафта предмет появится в вашем инвентаре.

### 🤝 Торговля с другими игроками
- Перейдите в **«Торговля»** (`/trade.html`).
- Укажите ID своего персонажа и ID персонажа, с которым хотите обменяться.
- В полях «Предлагаемые предметы» и «Запрашиваемые предметы» укажите JSON-список предметов с их количеством (например, `[{"itemId":"sword1","itemName":"Меч","quantity":1}]`).
- Укажите количество золота, которое вы предлагаете и запрашиваете.
- Нажмите **«Создать предложение»**.
- Другой игрок увидит ваше предложение (в будущем – в списке активных предложений) и сможет принять, отклонить или отменить его.
- После принятия предметы и золото автоматически перейдут к соответствующим сторонам.

### 💬 Диалоги с NPC
- Перейдите в **«Диалог»** (`/dialog.html`).
- Введите ID диалога (если он уже начат) и нажмите **«Загрузить состояние»**, чтобы увидеть текущий текст NPC и варианты ответов.
- Чтобы начать новый диалог, укажите ID NPC и ID своего персонажа, затем нажмите **«Начать»**.
- Выбирайте варианты ответов, нажимая на соответствующие кнопки. Диалог может содержать проверки навыков, ветвления и выдачу квестов/предметов.

### 🗺️ Путешествия
- Перейдите в **«Путешествия»** (`/travel.html`).
- Введите ID персонажа.
- Вы можете:
  - **Переместиться на тактической карте** (укажите координаты X и Y и нажмите «Переместиться»).
  - **Использовать Dash** (удвоить скорость на текущий ход).
  - **Совершить специальное перемещение** (лазание, плавание, полёт, копание) – укажите тип и дистанцию.
  - **Начать путешествие по глобальной карте** (укажите ID группы и ID маршрута) – это продвинет время и может вызвать случайные встречи.

### 💡 Советы
- Сохраняйте токен в безопасном месте (он автоматически хранится в `localStorage`).
- При возникновении ошибок смотрите сообщения в правом нижнем углу (всплывающие уведомления) или в консоли браузера (F12 → Console).
- Используйте WebSocket-клиент (`/game.html`) для получения обновлений в реальном времени.

## 🧙‍♂️ Для Мастера подземелий (DM)

*Вы — архитектор мира, управляете кампанией, NPC, монстрами и сюжетом. Инструменты DM помогут вам модерировать игру, создавать квесты, управлять боями и отслеживать состояние мира.*

### 🛠️ Инструменты Мастера
- После входа в систему перейдите на страницу **«DM Tools»** (например, `/dm/combat.html` для управления боем, `/dm/campaign.html` для кампаний).
- В консольном интерфейсе (или веб-интерфейсе) выберите нужный пункт меню.

### 📋 Основные возможности
| Команда | Описание |
|---------|----------|
| **Campaign Overview** | Просмотр состояния кампании (время, погода, флаги, квесты, участники). |
| **Party Status** | Сводка по всем персонажам группы: HP, условия, уровень, инвентарь. |
| **Combat Tracker** | Мониторинг активного боя: инициатива, раунды, текущий ход, состояния. |
| **Quick Actions** | Быстрое нанесение урона, лечение, наложение/снятие состояний, изменение золота. |
| **Spawn Monster / NPC** | Создание нового существа с заданными параметрами (имя, HP, характеристики). |
| **Manage Quests** | Создание, принятие, завершение или провал квестов. |
| **World State** | Изменение времени суток, погоды, глобальных флагов. |
| **Inspect Character** | Просмотр полной информации о любом персонаже (включая скрытые параметры). |
| **Crafting Management** | Просмотр всех активных процессов крафта в кампании, принудительное завершение. |
| **Trade Monitoring** | Просмотр всех предложений обмена между игроками, возможность отмены. |

### ⚡ Принудительные изменения (Override)
- Используйте класс `OverrideCommands` (через код или специальный интерфейс) для:
  - Воскрешения / убийства персонажей.
  - Выдачи предметов и золота.
  - Изменения характеристик и уровня.
  - Телепортации и управления боем.
  - Установки глобальных флагов.

### ↩️ Отмена действий (Undo)
- Мастер может отменить последнее действие любого игрока в сессии через `DmUndoManager` или через WebSocket-команду `undo_request`.
- Это полезно при ошибках или нечестной игре.

### ⚠️ Внимание
- Все изменения, сделанные через инструменты Мастера, **немедленно применяются** и сохраняются в Event Store.
- Будьте осторожны — отменить некоторые действия сложно (хотя Undo доступен).

## 💻 Для разработчика / администратора

*Вы отвечаете за код, инфраструктуру и развёртывание. Здесь — краткий обзор архитектуры и ключевых моментов, включая новые компоненты.*

### 🏗️ Архитектура системы (обновлённая)
- **Event Sourcing + CQRS** – все изменения хранятся как события в PostgreSQL; read-модели строятся проекциями.
- **DDD** – агрегаты, саги, value objects, доменные события и команды.
- **Сообщения** – команды, запросы и события проходят через шину (`InMemoryBus` или `RabbitMQ`).
- **Кеширование** – Redis для ускорения чтения проекций (опционально).
- **Логирование** – Serilog с выводом в консоль и файлы.
- **Валидация** – FluentValidation для всех входных моделей.
- **Swagger/OpenAPI** – интерактивная документация по адресу `/swagger`.

### 🗄️ Основные компоненты (новые и обновлённые)
| Компонент | Назначение |
|-----------|------------|
| `IQuestTrackingStore` | Хранение связей между персонажами/предметами и активными квестами (используется в сагах). |
| `CraftingService` | Управление рецептами, процессами крафта, проверка компонентов и выдача предметов. |
| `TradeService` | Создание, принятие, отклонение предложений обмена между игроками. |
| `DialogService` | Управление диалоговыми деревьями, проверки навыков, эффекты. |
| `TravelService` | Перемещение по тактической и глобальной карте, путешествия, расход ресурсов. |
| `UndoManager` | Отмена/повтор действий (поддерживается через WebSocket и DM-интерфейс). |

### 🔧 Настройка окружения (дополнения)
- Для работы крафта, торговли, диалогов и путешествий необходимы соответствующие репозитории (InMemory или БД) – уже реализованы.
- Redis опционален, но рекомендуется для кеширования проекций.
- Для диалогов требуется загрузка диалоговых деревьев (можно через JSON-файлы или БД).

### 📦 Запуск и отладка (без изменений)
```bash
dotnet restore
dotnet run --urls="http://localhost:5000"
```
- При первом запуске автоматически применяются миграции DbUp.
- Для просмотра логов используйте вывод консоли или файлы `logs/dnd_game-*.txt`.

### 🧪 Тестирование (дополнено)
- Добавлены интеграционные тесты для `QuestSaga` и `LevelUpSaga` (проверяют полный цикл).
- Нагрузочный тест расширен для проверки API и WebSocket.

### 🚀 Развёртывание (без изменений)
- Используйте `Dockerfile` и `docker-compose.yml` для поднятия полного стека (app + postgres + rabbitmq + redis).
- Настройте переменные окружения для продакшена (пароли, секреты JWT).

### 📚 Полезные ресурсы
- Документация по используемым библиотекам (Npgsql, RabbitMQ.Client, StackExchange.Redis, OpenTelemetry, Serilog).
- Книги по DDD и Event Sourcing (см. основную литературу).
